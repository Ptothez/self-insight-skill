# 模块目录 / Module catalog

路径相对于主入口的 SKILL.md。先读主模块，再按实际缺口选择最多两个辅助；安全边界优先。

## 自我认知 / Self-awareness

- 路径：`../self-insight-self-awareness/SKILL.md`
- 用途：梳理自我评价、当下感受与反复出现的关系模式。
- 条件：不限于家庭。用户希望认识自己，而非仅索取一个事实答案。

## 界限 / Boundaries

- 路径：`../self-insight-boundaries/SKILL.md`
- 用途：厘清责任、拒绝与关系中的安全边界。
- 条件：适用于亲密关系、家庭、工作和其他人际关系；不是控制他人的方法。

## 理解情绪 / Understanding Emotions

- 路径：`../self-insight-emotions/SKILL.md`
- 用途：帮助照护者理解和回应孩子的情绪。
- 条件：本模块主体仍为儿童与照护者，不是通用成人情绪治疗。成人自我探索交回主入口判断。

## 规则与行动 / Rules & Actions

- 路径：`../self-insight-rules-and-actions/SKILL.md`
- 用途：帮助父母澄清管教目标，落实清楚且适度的规则。
- 条件：本模块保留亲子管教范围，不用于管理配偶、同事或让其他成年人服从。

## 依赖与失控 / Dependency & Loss of Control

- 路径：`../self-insight-dependency/SKILL.md`
- 用途：理解儿童依赖行为带来的影响，探索家庭层面的支持。
- 条件：聚焦儿童、青少年的依赖困扰与照护者应对；不诊断成瘾，不提供戒断或药物处置。

## 阶段与角色 / Stages & Roles

- 路径：`../self-insight-stages-and-roles/SKILL.md`
- 用途：帮助父母按孩子的发展阶段调整期待与相处方式。
- 条件：年龄与养育角色模块，不是成年人的职业阶段模型，也不是发育诊断工具。

## 内在能力 / Inner Capacities

- 路径：`../self-insight-inner-capacities/SKILL.md`
- 用途：帮助照护者支持孩子的独立、自控、共情和学习等内在能力。
- 条件：保留儿童能力培养语境，不把原有养育材料扩写成成人心理训练。

## 自我修养 / Personal Practice

- 路径：`../self-insight-personal-practice/SKILL.md`
- 用途：帮助父母从自身状态与相处方式入手，而非只要求孩子改变。
- 条件：原父母习惯模块；含自我照顾、关系质量、学习、情绪连接、提问、承认错误与协作，不等于一般时间管理。

## 专注力 / Focus

- 路径：`../self-insight-focus/SKILL.md`
- 用途：帮助照护者区分儿童专注困难、期待与环境因素。
- 条件：保留儿童养育范围；不诊断或排除 ADHD，不给药物建议，不用于证明某个孩子懒惰。

## 近邻区别

- 自我认知探索本人如何理解自己；界限处理责任与可以采取的边界行动，两者可以互相辅助。
- 规则与行动处理孩子的具体行为；理解情绪处理照护者如何回应孩子的感受；遇危险先保护。
- 阶段与角色看期待是否适龄；内在能力看如何支持长期能力；专注力看具体投入场景与干扰。
- 自我修养面向父母自己的状态与相处习惯；不是给所有成年人强配养育议题。
- 依赖与失控关注行为影响及支持需求，不仅是规则是否执行，也不提供成瘾诊断。

不适用时返回主入口说明范围，不能以名称相近替代适用性判断。不可访问的模块必须如实报告，不能假装已读取。
