# Version and Scope / 版本与范围

## Full Knowledge Edition · 2026-11-06

自观保留一个主入口和九个模块。原有方法、咨询流程、54 个知识／案例文件及 477 条原子均保留；补充库包含 13,044 条结构化记录，来自 242 份已提供文本的逐点提取和复核。

统一检索共 13,521 条记录。它们包括概念、步骤、适用条件、案例、反模式和来源说明，不代表 13,521 个互不重复的概念。新旧知识通过 2,363 条有条件的语义连接共同使用；模块的对象和范围不会因为检索命中而自动扩大。

Self Insight includes one entry point and nine modules. The original methods, dialogue flows, 54 knowledge and case files, and 477 atoms are preserved. The expanded library adds 13,044 structured records from 242 supplied texts. Unified retrieval includes both layers, with 2,363 conditional semantic links between them. Record counts are not counts of unique concepts.

## What Is Included / 包含什么

- 全部运行知识、匿名实践案例、模块方法与本地检索脚本；无需原课程、作者电脑路径、API 或账号。
- 来源使用稳定编号，不分发课程转写原件、私人笔记、身份映射、测试答案或内部审计回包。
- 原有匿名案例的正文不缩写；公开适配只处理私人标注和安装路径。

The package includes the complete runtime knowledge, anonymized cases, module methods and local search script. It does not include original course transcripts, private notes, identity mappings, test answers or internal audit responses. No author-specific paths, API credentials or source documents are required.

## Verification Boundaries / 验证边界

覆盖、引用、关系和文件完整性可通过工程检查核对；对话行为通过实际场景回归检查。历史模块页中的验收记录只说明当时版本，不自动证明任何后续版本。可执行不等于临床有效，来源忠实不等于独立科学认证；转写缺失的动作、案例结果和未证实的主张不补造。

Packaging and regression checks assess completeness and observable behavior, not clinical effectiveness. Course claims are not independent scientific validation. Missing source details remain unknown. Privacy and expression checks are not copyright permission or a legal guarantee.

涉及诊断、药物、自伤、伤人、虐待或其他紧急风险时，先处理安全与专业支持，不继续套普通成长对话。不要依据知识包自行用药，也不要把匿名案例当作对使用者的诊断。

Safety and qualified support take priority when diagnosis, medication, self-harm, violence or abuse is involved. Do not use this package to self-prescribe or diagnose a person from an example.
