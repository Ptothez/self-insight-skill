# 条件与流程（12 种成功的能力模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进、以及如何按用户目标选能力（不套 12 课顺序）。全文已脱敏。

## 一、进入条件（什么情境适合进本模块）

当问题的核心落在「孩子内在能力的培养」上，即以下任一情形，进入本模块：

- 想系统培养孩子的某一种或某几种底层能力（快乐、喜欢自己、独立、主动、自控、分轻重、共情、理解、处理矛盾、学习、纠错、容异见），但不知从何下手；
- 孩子的外在表现已让家长感到无力——无感躺平、自我否定、过度依赖、遇挫即弃、沉迷失控、忙乱无效、不会换位、不会表达、怕冲突或只会吵、厌学、死不认错、听不进批评；
- 家长意识到自己在「控制、代劳、逼、骂、贴标签」，想换成「种」的方式却不知具体怎么做；
- 家长想先从自身状态入手（自己先快乐、先自控、先独立），再反哺孩子。

## 二、排除条件 / 转介条件（什么情境不进本模块或需转介）

本模块只处理「内在能力的培养心法」，以下情境不归本模块：

| 情境 | 处理方向 |
|---|---|
| 具体技能训练（英语、钢琴、学科成绩等外在技能） | 本模块不讲技能，转对应技能 / 学科指导 |
| 具体行为管教的操作方法（孩子某行为如何纠正、如何立后果） | 转「管教」模块 |
| 孩子的情绪识别、命名与调节技术 | 转「情绪孩子」模块 |
| 孩子的上瘾行为（沉迷、失控及其干预） | 转「上瘾」模块 |
| 「不同年龄父母不同角色」的分龄细节 | 如实告知本模块不覆盖分龄差异；涉及分龄授权时不在此展开 |
| 精神疾病或心理障碍的诊断、治疗 | 转精神 / 医疗专业，不做诊断 |
| 临床焦虑、抑郁等已达疾病程度的状态 | 先就医处理，再回来看能力培养 |
| 急性自伤 / 自杀危机、家暴、虐待等人身安全风险 | 立即报警、送医，先保安全再谈培养 |
| 受生理 / 精神因素影响、难以自我控制（如成瘾已到临床程度） | 先就医处理生理 / 精神因素 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 转「界限」系列模块主导对外处置；本模块按分工配合 |

## 三、咨询候选流程（按卡点分环）

顺序即卡点顺序：**定位能力 → 判断卡点 → 给要点与最小行动**。每一环先判断卡点在哪，再对症推进；卡点没清，不跳到下一环。**不套 12 课顺序**——按用户当下的目标选能力，而不是按第一课到第十二课顺推。

| 环 | 任务 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介条件 |
|---|---|---|---|---|---|
| 定位能力 | 从目标出发，确定要培养哪一种能力 | 「你当下最想改变孩子的什么表现？这个表现背后，你觉得缺的是哪种能力？」 | 对照「能力速查表」（见第四节），让来访者圈出 1–2 个最匹配的能力 | 能用自己的话说出「我想培养的是 X 能力」 | 目标反复在多个能力间漂移、无主次，回本环重打地基；说不清目标者先做目标澄清 |
| 判断卡点 | 判断孩子当前卡在哪儿（缺根基 / 缺方法 / 父母示范缺位） | 「孩子现在具体卡在哪一步？是没机会做、不敢做，还是不想做？父母自己这方面做到什么程度？」 | 按该能力「父母先做到 → 拿走障碍 → 给机会」三问，判断卡点落在哪一层 | 能定位卡点属于「父母示范缺位 / 环境障碍 / 孩子缺机会」之一 | 触及孩子已到临床程度的情绪 / 行为问题，先转介（见上表） |
| 给要点与最小行动 | 给该能力的培养要点 + 一个可执行的最小行动 | 「这个能力的关键要点是什么？（一句话）你本周能先做的最小一步是什么？」 | 从该能力要点里挑 1 条，落成一个「本周最小行动」（如每天讲三件开心事、允许孩子独立做一个决定） | 产出一个具体、可执行、可复述的最小行动 | 反复给不出行动或给了不做，回「判断卡点」环；涉及人身安全转介 |

通用提醒：能力是「种」出来的，最小行动要落在「给环境、给机会、允许犯错、身教示范」上，而不是「更严地管、更用力地逼」；同一个要点不能照搬到不同年龄（本模块不覆盖分龄差异，涉及分龄授权时如实说明）。

## 四、按用户目标选能力（12 能力速查，不套课次）

| 用户目标 / 典型卡点信号 | 对应能力 | 一句话培养要点 |
|---|---|---|
| 孩子无感、躺平、总觉得没意思；或父母自己不快乐 | 获得快乐 | 父母先快乐 + 家庭氛围（幽默轻松安全积极、夫妻不撕扯、富足感——心理与安全感层面，非经济条件）+ 训练「标识快乐」 |
| 孩子自我否定、怕犯错、过度在意别人评价 | 喜欢自己 | 无条件接纳（不喜欢行为但永远爱你）+ 尊重倾听 + 欢迎犯错 + 认输认错 + 帮识别情绪 |
| 孩子凡事问父母、不敢做决定、怕犯错；父母过度代劳 | 独立 | 允许真实质疑 + 给独处白日梦自由时间 + 独立做决定 + 犯错后问「你学到什么」+ 孩子不求父母不帮 |
| 孩子遇挫就放弃、只抱怨不行动、信命敏感 | 主动积极 | 坚持（拆小、庆祝小成功、给长期责任）+ 破局四步（指认问题→列清单→挑方案→称赞行动）+ 安全港湾 |
| 孩子沉迷、明知该做却管不住自己 | 自控 | 拿走他控因素 + 以原则为中心 + 具体目标→评估行为→看清因果→可行计划→承担后果→巩固 |
| 孩子忙乱却重要事没做、拖延、分不清想要 vs 需要 | 分清轻重缓急 | 四象限 + 第二象限（重要不紧急）优先 + 想要 vs 需要 + 机会成本 + 延迟满足 |
| 孩子只顾自己、不会换位、只会争输赢 | 共情共赢 | 换位不下判断 + 识别对方情绪 + 讨价还价 + 求同存异 + 先讨价还价后立界限 |
| 孩子不会表达、感到不被理解、沟通冲突 | 理解和被理解 | 延展性问题 + 问感受不问事情 + 第二层信息 + 帮孩子说清 + 理解 ≠ 同意 |
| 孩子讨好型或刺猬型、怕冲突、只会忍或只会吵 | 处理矛盾 | 止损 + 找真正威胁点 / 情绪点 + 认识接受情绪 + 找共同点 + 把矛盾当成长机会 |
| 孩子厌学、只重成绩、失去好奇 | 学习 | 绝对安全环境 + 保护好奇 + 鼓励探索 + 把学习变好玩 + 做向导不做答案 + 用起来 |
| 孩子不认错、一被批评就炸、反复犯同样错 | 自我纠正 | 内疚而非羞耻 + 正确批评（陈述事实→我的感受→界限与后果）+ 给「再来一次」+ 好好对待提问 |
| 孩子听不进批评、爱抬杠、一被说就急 | 聆听不同意见 | 处理批评（冷静→澄清→要具体）+ 建多维思考（允许挑战你、从差异看共性）+ 善意 vs 恶意批评 |
