## 案例 1：全家禁止负面情绪，孩子变得面无表情

- **情境**：一名十来岁的孩子脸上长期没有表情，家人以为是面部神经问题，跑遍医院查不出问题，后被建议看心理辅导。
- **当事人做法**：这家人自己表现得异常「积极乐观」，从来不允许家里出现任何负面情绪——长辈去世他们不悲伤、不呈现，只允许有快乐。
- **老师反馈**：问题恰恰出在「只允许快乐、禁止悲伤」上——快乐的反面不是悲伤，而是无感 / 躺平；被禁止表达悲伤、担忧、愤怒的孩子，连快乐也感受不到了。辅导重点转向帮父母练习表达自己的正常负面情绪。
- **结果**：父母花了约半年才慢慢学会在家表达负面情绪，此后孩子脸上开始有笑容，也重新会哭泣。
- **适用条件**：家庭长期压抑负面情绪、只许积极。
- **知识节点**：第一课「快乐的反面不是悲伤，而是无感」「家庭氛围」。

## 案例 2：家境优渥的女孩深夜割伤自己

- **情境**：一位家境优渥的女孩，物质与教育资源都不缺，却深夜用刀割自己的手臂、用烟头烫自己。
- **当事人做法**：女孩反复自我伤害；家长困惑「她什么都不缺，为什么不喜欢自己」。
- **老师反馈**：优秀、有钱、漂亮都不等于喜欢自己——「获得越多越喜欢自己」是误区；关键不在「给更多」，而在让她建立自我认知与无条件接纳。
- **结果**：揭示「优秀 ≠ 自我接纳」的误区（长期结果未知）。
- **适用条件**：优渥家境却自我厌恶的孩子。
- **知识节点**：第二课「优秀 / 有钱 / 漂亮 ≠ 喜欢自己」。

## 案例 3：考砸后被寄宿家庭无条件接纳

- **情境**：一位年少出国读书的来访者，某科考得很差（近乎不及格），自己以为会被责备。
- **当事人做法**：寄宿家庭的姐姐没有责备，也没有追问「为什么考这么差」，而是照常接纳、让他知道「尽力即可被爱」。
- **老师反馈**：这是「无条件接纳」的完整示范——接纳的是人，不是成绩；一次被无条件接纳的经历，会成为人一生的底气。
- **结果**：当事人首次体验到无条件接纳，影响终身。
- **适用条件**：孩子因表现差而自我否定、害怕被否定。
- **知识节点**：第二课「无条件接纳：可能不喜欢你的行为，但永远爱你」。

## 案例 4：高学历夫妇想换房，被年迈父母反对后放弃

- **情境**：一对在海外工作的高学历夫妇想换一处房子，远在国内、对当地知之甚少的年迈父母强烈反对。
- **当事人做法**：夫妇从坚持到熬不过父母，最终放弃换房。
- **老师反馈**：能挣钱、能独立生活的人，不见得就是独立的人；经济独立是独立的最后一步，精神 / 心理不独立时，父母仍能「拿捏」你。
- **结果**：换房计划放弃（问题在于独立，不在房子）。
- **适用条件**：成年人能挣钱却仍被父母在精神 / 心理上牵制。
- **知识节点**：第三课「经济独立 ≠ 独立」「精神 / 心理独立」。

## 案例 5：丈夫每个假期都带全家回父母身边

- **情境**：一位已婚男士，每逢假期不是带全家回父母家，就是带父母出游，全家的旅行计划都以父母为先。
- **当事人做法**：夫妻因此从未真正按自己意愿度过假；妻子感到被边缘化。
- **老师反馈**：这是「心理不独立」——父母封闭、只有这一个孩子，于是孩子成了父母的责任；父母不能让孩子为自己买单，要对自己的生活负责。
- **结果**：婚姻关系恶化，来做婚姻辅导。
- **适用条件**：父母过度依赖子女、子女把父母当责任。
- **知识节点**：第三课「心理独立：你是你，我是我」「父母要体面退出」。

## 案例 6：大孩子首次攀岩被困，最终登顶

- **情境**：一位家长的大孩子第一次攀岩，爬到中途被困住，进退两难。
- **当事人做法**：孩子一度想放弃，但在鼓励下坚持，最终自己登顶。
- **老师反馈**：这是「主动积极 = 坚持 + 破局」的具象示范——真正的主动积极不是好心态、正能量，而是在「坚持不下去」时既咬牙坚持、又想出办法破局。
- **结果**：孩子登顶，形成「我做得到」的体验。
- **适用条件**：孩子遇挫想放弃、缺坚持与破局体验。
- **知识节点**：第四课「主动积极 = 坚持 + 破局」。

## 案例 7：同学生日没请自己的孩子

- **情境**：班里有同学过生日，请了大半个班的同学，却没有请自己的孩子。
- **当事人做法**：孩子回家很沮丧，抱怨「大家都不喜欢我」。
- **老师反馈**：先承接情绪（孩子正在经历挫折），再把它当作破局训练的机会——走「指认问题 → 头脑风暴列清单 → 挑可行方案 → 称赞行动」四步，让孩子从「被动的受害者」变成「能改变处境的人」。
- **结果**：孩子学会「我可以做些什么改变处境」，而不是停在抱怨。
- **适用条件**：孩子遭遇社交挫折、习惯性归因「大家都不喜欢我」。
- **知识节点**：第四课「破局四步」「失败是机会」。

## 案例 8：被送进强制戒网学校，出校即复发

- **情境**：一位企业家的孩子沉迷网络，被送进强制戒网学校。
- **当事人做法**：学校强制断网、严格管控；孩子在校期间「表现良好」。
- **老师反馈**：这是「他控」而非「自控」——被控制养不出自控；一旦外部控制撤除，行为立刻复发。自控的关键是拿走他控因素、让孩子自己一次次成败累积。
- **结果**：出校即复发，强制戒断失效。
- **适用条件**：家长用强制手段管沉迷、追求「立刻管住」。
- **知识节点**：第五课「自控最重要的是拿走他控的因素」。

## 案例 9：整日忙碌却一事无成

- **情境**：一位在名校读书的人，每天忙得不可开交，却总觉得自己「该做的都没做」。
- **当事人做法**：把大量时间花在紧急琐事上，重要的事一再拖延。
- **老师反馈**：这是不会「分清轻重缓急」——重心应放在「重要但不紧急」的象限（关系、计划、学习、预备），而不是被「紧急」追着跑；复盘后识别「该做未做」，才能把时间还给真正重要的事。
- **结果**：复盘后识别出「该做未做」的环节。
- **适用条件**：忙乱、拖延、重要事总被紧急事挤掉。
- **知识节点**：第六课「四象限」「第二象限优先」。

## 案例 10：孩子想晚睡看电影，讨价还价

- **情境**：孩子想晚睡看电影，与父母的安排冲突。
- **当事人做法**：父母没有一口拒绝，而是让孩子练习「讨价还价」。
- **老师反馈**：资源有限时，让孩子学会妥协与讨价还价——指认「我想要什么、为什么应得、拿什么交换、对他人有什么影响、他人感受」；先讨价还价、后立界限，价值与原则不进入讨价还价。
- **结果**：孩子学到交换与同理，双方各得所需。
- **适用条件**：孩子只顾自己、不会换位、只会「要」不会「谈」。
- **知识节点**：第七课「共赢」「讨价还价训练」「先讨价还价后立界限」。

## 案例 11：母亲反复追问「你为什么哭」

- **情境**：兴趣班门口，一个孩子大哭着扑进妈妈怀里。
- **当事人做法**：妈妈一直反复追问「你为什么哭」。
- **老师反馈**：这是反例——让孩子感到被理解，要「问感受而非只问事情」；只追问原因、不进入孩子的情绪世界，孩子感受不到被理解，以后也难以深刻理解别人。
- **结果**：孩子未被真正理解（反例示范）。
- **适用条件**：孩子情绪爆发时，家长急于「问清楚」而忽略共情。
- **知识节点**：第八课「问感受而非问事情」「延展性问题」。

## 案例 12：跨国夫妻为戴口罩当街争吵

- **情境**：一对跨国夫妻，一方坚持戴口罩、一方强烈反对，为此当街争吵。
- **当事人做法**：两人各执一词，吵到当街失态。
- **老师反馈**：矛盾根源不是「戴口罩」这件小事，而是「因不同感受到威胁」——对方的不同触碰了自己的安全感，于是把「意见不同」升级成了「人身对立」；处理矛盾要先找到真正的威胁点 / 情绪点。
- **结果**：揭示「矛盾 = 因不同感受到威胁」的机制。
- **适用条件**：为小事反复起冲突、只停留在表面争执。
- **知识节点**：第九课「威胁产生矛盾」「发现真正的矛盾点」。

## 案例 13：足球队孩子与「不听指挥」的队友

- **情境**：足球队里，一个孩子嫌另一个队友「不听指挥」、总不配合。
- **当事人做法**：引导孩子先找「我们共同的点」——「我们其实都想赢球」。
- **老师反馈**：处理矛盾的关键一步是「找共同点」；找到共同点后，对立变成合作，分歧被共同目标承接。
- **结果**：队友听劝、进球，两人成为好友。
- **适用条件**：孩子与同伴 / 家人陷入对立、各说各话。
- **知识节点**：第九课「找共同点」「把矛盾看作关系成长机会」。

## 案例 14：家庭游戏里玩出心算

- **情境**：一个孩子平时对数学提不起劲，却在一次家庭桌游里表现出惊人的心算。
- **当事人做法**：家人在游戏中发现孩子心算很快、很投入。
- **老师反馈**：孩子在「玩」里找到了乐趣，学习就变得容易——学习能力靠好奇、探索、喜欢，把学习变「好玩」、让学到的东西「用起来」，比逼着学有效得多。
- **结果**：孩子的数学兴趣被激活。
- **适用条件**：孩子对某门学科提不起劲、被逼着学。
- **知识节点**：第十课「好奇 / 探索 / 喜欢」「把学习变好玩、用起来」。

## 案例 15：大孩子嫉妒推倒妹妹

- **情境**：家中大孩子因嫉妒，动手推倒了妹妹。
- **当事人做法**：家长没有骂「你是坏孩子」，而是让大孩子知道「推妹妹这个行为」伤害了别人、让妈妈伤心。
- **老师反馈**：这是「内疚 vs 羞耻」的训练样本——让孩子对「行为错了」感到内疚（后悔改），而不是对「我是坏孩子」感到羞耻（想隐藏）；批评用「陈述事实 → 我的感受 → 界限与后果」，不用讽刺羞辱。
- **结果**：孩子区分「行为错了」与「你是坏孩子」，愿意改。
- **适用条件**：孩子犯错后家长容易上纲上线到「人品」。
- **知识节点**：第十一课「内疚（悔改）vs 羞耻（隐藏）」「正确批评三步」。

## 案例 16：朋友被骗，配偶称「就当交学费」

- **情境**：一位朋友被骗走一笔钱，懊恼不已。
- **当事人做法**：其配偶没有责备，反而轻松地说「就当交学费」。
- **老师反馈**：把犯错「轻松化」——让孩子（以及成人自己）不把犯错当羞耻，才有勇气承认和纠正；其孩子也因此极不怕犯错。
- **结果**：其孩子养成极不怕犯错、敢尝试的品性。
- **适用条件**：家庭把「犯错」等同于「丢脸 / 羞耻」。
- **知识节点**：第十一课「把错误正面化」「犯错不可耻」。

## 案例 17：大孩子易怒砸门，练深呼吸 + 数数

- **情境**：一位家长的大孩子个性要强，一遇不顺就大吼、甚至砸门。
- **当事人做法**：引导孩子练「深呼吸 + 数数」，先让自己冷静。
- **老师反馈**：处理批评 / 不同意见的第一步是「保持冷静」（深呼吸、数数），第二步是重复 / 澄清所听，第三步要具体批评；先接住情绪，再谈内容。
- **结果**：一段时间后孩子明显更自控、不再动辄爆发。
- **适用条件**：孩子一被说就急、情绪先于理智。
- **知识节点**：第十二课「处理批评第一步：保持冷静」。
