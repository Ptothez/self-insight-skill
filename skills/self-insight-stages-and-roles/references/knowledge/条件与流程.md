# 条件与流程（年龄角色模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进。「孩子多大」是本模块的第一问题，一切判断先锁定孩子年龄与阶段，再看具体主题。全文已脱敏。

## 一、进入条件（什么情境适合进本模块）

当问题落在「不知道这个年龄该对孩子做什么、该扮演什么角色」上，即以下任一情形，进入本模块：

- 发现孩子「以前很听话、突然叛逆」，或「说了不听、讲道理没用」，怀疑是孩子有问题而非自己角色没跟上；
- 用同一套育儿方法应对不同年龄的孩子，孩子却越来越难管、越来越疏远；
- 对孩子抱有某个期待（自控、分享、懂事、独立），孩子总达不到，父母因此焦虑、失望、愤怒；
- 感到自己「付出很多、孩子却不领情」，爱没被孩子接收到；
- 卡在某个具体冲突/沟通/情绪场景里，想知道「这个年龄的正确做法是什么」。

## 二、排除条件 / 转介条件（什么情境不进本模块或需转介）

本模块只处理「按年龄匹配角色与做法的认知与能力」，以下情境不归本模块，应转介或另配他处：

| 情境 | 处理方向 |
|---|---|
| 学科学习、成绩与升学的具体辅导 | 转学业/学科相关方向 |
| 专项界限训练、品德习惯专项（管教、界限、习惯养成） | 转对应专项模块/系列 |
| 成瘾相关（成瘾干预、疑似成瘾） | 干预转「上瘾」模块/系列；疑似成瘾作为疾病需诊断与治疗的，转精神/医疗专业，不做诊断 |
| 精神疾病或心理障碍（如选择性缄默症等）的诊断与治疗 | 转精神/医疗专业，不做诊断 |
| 疑似被性侵 | 先保安全、必要时报警，心理评估与治疗转专业 |
| 原生家庭的深度疗愈（父母自身情绪、童年创伤的深挖） | 本模块仅在「父母情绪健康是必要条件」层面点到，深挖疗愈转专业辅导 |
| 急性自伤/自杀危机、家暴等人身安全风险 | 立即报警、送医，先保安全再谈角色与做法 |
| 父母自身受精神状况或药物影响、难以自我控制 | 先就医处理生理/精神因素，再回来看育儿 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 转「界限」系列模块主导对外处置；本模块按分工配合 |

补充排除：视频/英文字幕段、影视片段内容不进入知识包；口述数据不写数字，只保留机制判断。

## 三、咨询候选流程（按卡点分环）

顺序即卡点顺序：**定位年龄 → 定位主题 → 给年龄层要点与最小行动**。每一环先判断卡点在哪，再对症推进；卡点没清，不跳到下一环。「孩子多大」贯穿始终，是第一问题。

| 环 | 对应内容 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介条件 |
|---|---|---|---|---|---|
| 定位年龄与阶段 | 第一课角色总纲、第三课大脑发育节点 | 先只问年龄：「孩子现在多大（几岁几个月）？」；等答复后再问「你说的情况具体发生在什么场景？」 | 把孩子的年龄归入对应年龄带，并说出该年龄带父母的大致角色 | 能准确说出孩子年龄，并定位到本模块的年龄带 | 孩子年龄信息缺失、或当事人反复答非所问（如只说「我孩子不听话」不说年龄），回本环先问清年龄 |
| 定位主题 | 第二～八课（情绪联结/矛盾/情感需求/沟通/表达爱/期望） | 「你当前最卡的是哪一类：情绪、沟通、矛盾冲突、表达爱，还是期望落差？」 | 把问题对应到 1–2 个主题，排除不相关主题 | 能明确当前主题（情绪/沟通/矛盾/爱/期望其中之一） | 问题同时涉及精神疾病、人身安全、成瘾等（见上表），先转介，不在此环展开 |
| 给年龄层要点与最小行动 | 对应主题的年龄分层做法 | 「这个年龄，这一主题下，你试过什么做法？哪些无效？」 | 按该年龄带给出 1–2 条要点 + 1 个「最小行动」（可当天做、可测量、带后果或带恩典） | 产出至少一条匹配当前年龄的最小行动 | 最小行动做不出来、或给成惩罚/威胁/讲大道理，回本环辨析「该年龄的做法」 |

通用提醒：同一主题在 0–25 岁有多个年龄带，做法从「供给/照顾」→「教导/支持」→「鼓励/合作」→「放手/尊重」递进；先定位年龄，再定位主题，是防止「拿对的做法用错年龄」的关键。父母情绪健康是全模块反复强调的必要条件，若父母自身情绪未处理，先回到「处理自己的问题」。

## 四、「孩子多大」：第一问题与年龄带速查

本模块第一问永远是「孩子多大」，因为一切做法都以年龄为横轴。速查各年龄带核心一句话（详细要点见理念框架）：

| 年龄带 | 父母角色 | 该年龄带最核心的一句话 |
|---|---|---|
| 0–1.5 岁 | 供应者 | 给足睡眠、安全环境、身体接触与及时回应，不讲道理 |
| 1.5–2 岁 | 教导者 | 讲结果不讲道理，温柔界限，允许说「不」与犯错 |
| 3–7 岁 | 支持者／鼓励者（3–5 支持者行 + 6–7 鼓励者行同用） | 可衡量界限 + 告知后果允许选择 + 恩典，培养「对自己说不」 |
| 6/7–12 岁 | 鼓励者 | 鼓励犯错、肯定语言、高质量陪伴，顶嘴是好事 |
| 13–18 岁 | 导师 | 无条件爱与接纳、倾听多于解决、提供帮助（赋能）、表达信任 |
| 18/19–25 岁 | 朋友 | 尊重隐私与独立、礼貌与界限、为过去道歉并改正 |

定位年龄时注意：按「当前年龄」做，不回溯补救过去；若孩子出现「反幼」现象（如 14 岁求婴儿式抱），先委婉排查性侵等异常，再说明某阶段需求未获满足：仍按当前年龄扮演角色、用当前年龄的方式满足，而不是退回过去的喂养方式。
