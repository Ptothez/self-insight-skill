# 概念关系（年龄角色模块）

> 本文件整理概念之间的因果与条件关系。每个关系统一按四问展开：**什么条件下影响什么 / 如何识别 / 怎样推进 / 何时不成立**。全文已脱敏。

## 一、年龄阶段 → 父母角色（本模块总关系）

- **什么条件下影响什么**：孩子的心理发育处于哪个年龄阶段，决定了父母该扮演什么角色——供应者（0–1.5）、教导者（1.5–2）、支持者（3–5）、鼓励者（6–12）、导师（13–18）、朋友（18–25）。角色不随年龄调整，孩子会「卡」在该阶段，成年后反复追溯过去。
- **如何识别**：孩子「以前很听话突然叛逆」、说了不听、爱没被接收到、或出现反幼现象（大孩子求婴儿式抱、退回吃手等），都提示父母的角色仍停在更早的年龄。
- **怎样推进**：先锁定孩子当前年龄，再按该年龄的角色要点行动（见理念框架六段清单）；按当前年龄做，不回溯补救过去。
- **何时不成立**：大样本规律、个体差异存在；病理/发育异常、精神疾病需另走医疗路径，不套用角色清单。

## 二、年龄阶段 → 能力边界（什么年龄能理解什么）

- **什么条件下影响什么**：大脑发育到哪一步，决定孩子「能理解什么、做不到什么」：婴幼儿听不懂道理（只能讲结果）；三岁半–四岁自控才萌芽；四–五岁才懂分享轮流；约八岁才听懂简单行为指示；12 岁后灰质修剪、前额叶最晚成熟，故青少年冲动非「叛逆」。
- **如何识别**：父母因「孩子做不到」而焦虑、以为孩子故意气自己、或花大价钱「补」孩子年龄没到的能力（如给小婴儿做早教卡片）——本质是不懂年龄与能力边界。
- **怎样推进**：把期待降到该年龄大脑能达到的水平；用「讲结果不讲道理」「正向指示性语言」「可测量后果」替代讲道理与惩罚。
- **何时不成立**：个体差异存在；已到发育节点仍持续做不到、或伴其他异常，需排除发育/精神问题，不简单归为「还没长好」。

## 三、大脑发育 ↔ 年龄（脑发育决定冲动与自控）

- **什么条件下影响什么**：前额叶是「刹车」，约 25 岁才完全成熟；12–19 岁青少年靠杏仁核（「只有油门没有刹车」）做决定，故冲动、情绪化、攻击性是大脑发育的必经状态，而非「叛逆期」的品德问题。
- **如何识别**：青少年一会儿觉得自己是全世界最好、一会儿最差；情绪起伏大；易冲动做后悔事——这些是灰质修剪/整合带来的混乱，不是针对父母。
- **怎样推进**：前期打好基础、赋能孩子、保持信任与影响力；经常与孩子讨论行为后果以强化前额叶；不贴「叛逆」标签。
- **何时不成立**：若前期养育长期错位、父母已失去影响力，则「冲动」叠加缺管教会更难控；涉违法/自伤行为仍需硬性干预与专业介入。

## 四、年龄 → 沟通方式（不同年龄怎么说话）

- **什么条件下影响什么**：年龄决定孩子「能听什么、愿意听什么」，故沟通方式必须随年龄换——话唠（0–3）→ 感觉（4–8）→ 高质量（9–12）→ 开放（13–18）→ 礼貌/界限（19–25）。
- **如何识别**：小的时候「讲道理听不懂」、长大「听得懂却不愿听」，是父母把「沟通 = 把观点植入对方」的方向性错误，而非孩子的问题。
- **怎样推进**：小龄用身体/表情/语气、给足思考时间、不替说完；大龄倾听多于解决、分享生活、不做独裁者、承认不足、尊重拒绝。
- **何时不成立**：父母情绪健康是必要条件；分享生活须区分「哪些可分享、哪些不」；涉及人身安全（如深夜外出）仍要明确表达担忧与界限，不因「尊重」而放任。

## 五、年龄 → 矛盾处理（处理方式随年龄变化）

- **什么条件下影响什么**：年龄决定孩子能否理解界限、能否承担后果，故矛盾处理随年龄变：0–3 岁简单明确、正向指示、温柔坚定制止；3–7 岁可衡量界限 + 告知后果允许选择 + 夹带恩典；8–12 岁告知生理变化、数到十、陈述情绪、3R 道歉、找解法；13–18 岁真实表达感受、交换意见、准备妥协、需要则道歉；19–25 岁为过去道歉、以尊重隐私/立界限/避免道德绑架来改正。
- **如何识别**：父母常用的错误处理方式（忽略、哄、体罚、强压、惩罚、恐吓、语言暴力、行为威胁、被动攻击、冷嘲热讽）随孩子年龄「升级」——小时候压得住，压不住的那天孩子用同样方式反击。
- **怎样推进**：用「界限 + 后果 + 恩典」替代「吼与压」；培养孩子「对自己说不」的能力；父母先处理自己的情绪与原生家庭问题。
- **何时不成立**：有矛盾不代表谁有错；但若已涉自伤/自杀、家暴等风险，立即报警送医，不在此环用「后果」处理。

## 六、年龄 → 表达爱（爱的语言随年龄变化）

- **什么条件下影响什么**：孩子在每个年龄段接收爱的方式不同，故「爱的语言」要匹配年龄：身体接触（0–2）→ 高质量陪伴「三同一」（3–7）→ 肯定的语言（8–12）→ 提供帮助（13–18）。
- **如何识别**：父母「在等感谢、孩子在等道歉」——给出去的爱不是孩子需要的爱，孩子感受不到，形成两败俱伤；或付出一切孩子却拼命挣脱、痛恨这种爱。
- **怎样推进**：按年龄用对爱的语言；13–18 岁「提供帮助」的终点是赋能与放手（主动营造环境 + 被动提供、向孩子求助、做安全树洞），不是替他解决。
- **何时不成立**：爱的量不等于爱对了；但「匹配年龄」不否定身体接触、陪伴等在任何年龄都重要——只是该年龄有「最关键」的那一种；18 岁前没感受到的爱，之后更难、需父母更主动更耐心地重建，但依然可能——是强度与难度的变化，不是定局。

## 七、年龄 → 期望（期望要匹配发展阶段）

- **什么条件下影响什么**：期待过高设下「必败目标」，长期捆绑、压制孩子，五年十年后才显现；期待过低（孩子已六岁仍当三岁待）则养出妈宝巨婴。故期望必须随发展阶段调整。
- **如何识别**：七大错误期待——①孩子能控制情绪；②做到过一次就该一直做到；③孩子长大就会明白；④常提醒不足能促进步；⑤孩子能感受到爱；⑥我给你爱你就要接受；⑦孩子至少像其他孩子。
- **怎样推进**：控制力如肌肉需练习，父母当「健身教练」（示范、鼓励、赞美每一点进步）；控制情绪是伪命题，应控制情绪背后的行为；做错了及时真诚道歉；按年龄给正确期待（0–4 勿期待自控/分享，5–9 黄金年龄植入情绪词汇与金钱观，10–18 睡足、允许示弱、保护仍是首要，19–25 独立/感激与否看以前怎么教）。
- **何时不成立**：不是「不要期望」，而是「期望要匹配发展阶段」；大样本规律、个体差异存在。

## 八、情绪联结随年龄的变化

- **什么条件下影响什么**：情绪联结是其他一切养育的前提；联结方式随年龄变（0–2 安全一致环境/允许自我安抚/匹配表情/及时满足；3–4 同情加称赞/讲故事/积极语言/庆祝进步；5–8 指认而不改变情绪/正常化/做真实父母；9–12 做榜样/欢迎朋友/聆听/公开谈性；13–17 归属感/情绪界限/聊天/尊重不同；18–25 反射情绪/欣赏优点/尊重隐私）。联结好 → 五项关键技能；联结失败 → 社交恐惧、讨好型人格、积怨、上瘾。
- **如何识别**：孩子失联的信号——不再向父母哭、不敢说真实原因、选择性沉默、长大后既爱父母又怕亲近父母。
- **怎样推进**：5 岁前是「小窗口」，越早联结越省力；父母先做真实的人、接纳负面情绪、正常化情绪，不急着「改善」孩子的难过。
- **何时不成立**：父母情绪健康是必要条件；当恐惧来自真实的人身安全威胁时，不能以「正常化情绪」轻描淡写，先保安全。
