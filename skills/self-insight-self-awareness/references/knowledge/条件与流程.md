# 条件与流程（自我认知模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、候选咨询如何按入口判断推进。全文已脱敏。
>
> **证据等级**：主体 A2（七课同期笔记，非逐字稿）+ B 层（SOP 衍生）；候选流程为 B 层草案归纳，逐项回指 A2 课程问题。本模块不复制旧 10 轮咨询的固定流程（旧实现保留为回归基线）。

## 一、进入条件（三类入口）

当问题落在「自我认知与内在重构」上，且属于以下任一入口，进入本模块：

- **自我梳理入口**：用户主动想做系统的自我梳理，想搞清楚「我是谁、我的优缺点、我为什么变成现在这样」；
- **焦虑事件入口**：用户带来一个当下的焦虑 / 情绪事件，想弄清楚「我到底在焦虑什么」；被人冒犯、心里过不去、纠结「该不该回怼」这类当下事件，同样走此入口；
- **信念线索入口**：用户已经带着一个核心信念线索（如「我觉得自己不够好」「我不重要」）进来，想验证或定位。

三类入口分别对应不同的推进起点（见第三节），不要求一律从第一课「优缺点」开始。

## 二、排除条件 / 转介条件

本模块只处理「自我认知与内在重构」的引导。以下情境不归本模块，应转介或另配他处：

| 情境 | 处理方向 |
|---|---|
| 严重精神症状（抑郁、焦虑症等达到临床程度）的诊断、治疗 | 转精神 / 医疗专业，不做诊断 |
| 急性自伤 / 自杀危机、家暴等人身安全风险 | 立即报警、送医，先保安全 |
| 深度创伤议题（触及原生家庭深伤且反复崩溃） | 转团体辅导 / 专业咨询 |
| 具体行为管教的操作方法 | 转「管教」系列模块 |
| 情绪识别、命名与调节的技术训练 | 情绪轮作为横向辅助工具按需使用，情绪调节技术转「情绪」系列模块 |
| 用户只要一个「快速答案 / 一句话结论」、不愿做自我梳理 | 不适用，先澄清预期 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 转「界限」系列模块主导对外处置；本模块按分工配合 |

## 三、候选咨询流程（按入口判断，不复制旧 10 轮）

三个入口对应三种推进路径；每轮一个主要推进目标，按卡点选素材，不要求从头走七课。

### 入口一：焦虑事件入口（从第六课下探）

- **判断依据**：用户带来当下焦虑 / 情绪事件（含被人冒犯后纠结「该不该回怼」这类当下事件）。
- **最少询问**（按需取 1–2 个）：① 最近让你焦虑的一件事是什么？② 这件事具体「意味着」什么（可连续追问「意味着……意味着……」）？
- **最小行动**：沿「意味着链」下探，直到触及核心信念；再按需回溯第 2 / 3 / 4 / 5 课素材补齐伤害、谎言、人设。
- **停止条件**：用户能说出「这件事触动了我的核心信念（如「我不够好」）」且情绪平复；或连续两轮无法下探（转回澄清，不硬套）。
- **转介条件**：下探中出现严重精神症状、自伤倾向 → 停止深挖，转专业。

### 入口二：系统梳理入口（按七课序推进）

- **判断依据**：用户主动做系统自我梳理。
- **最少询问**（第 1 课起点）：① 我的优缺点分别是什么？② 这其中有怎样的谎言？
- **最小行动**：按第 1 → 7 课顺序逐课推进（凝视自己 → 原生家庭 → 父母图片 → 打破人设 → 灵魂四问 → 焦虑 → 重写故事），每课只问该课核心问题，收集碎片信息，最后用第七课七步模板收束。
- **停止条件**：完成一轮七步重写故事，或用户明确只想停留在某一课深入。
- **转介条件**：推进到原生家庭 / 父母图片时触及深伤且反复崩溃 → 转深度疗愈 / 团体辅导。

### 入口三：信念线索入口（从第五课验证）

- **判断依据**：用户带着核心信念线索（如「我不够好」）进入。
- **最少询问**（第 5 课灵魂四问）：① 记忆中最伤害的一件事是？② 这件事伤害了我的？③ 拿走了我什么力量？④ 导致我对自己的核心信念是？
- **最小行动**：用灵魂四问验证 / 定位核心信念；再决定向哪一课回溯（若线索偏「关系」，回溯第 3 课；偏「人设」，回溯第 4 课；偏「当下焦虑」，回到第 6 课）。
- **停止条件**：用户能辨认并接受「我的核心信念是……（它是一件穿上真理外衣的羞耻）」，且定位完成。
- **转介条件**：信念涉及严重自我否定且伴随自伤倾向 → 转专业。

通用提醒：核心信念 14 种清单为辅助识别参考，不作绝对标准；灵魂四问的定位由用户自己说出（镜像式，不替用户下结论），定位一旦完成则明确告知其为错误认知（敢于定性）。

## 四、与旧 10 轮咨询流程的关系

旧 10 轮咨询（9+1 节奏、固定轮次、每轮 300 字、Turn 10 强制七步重写）保留为回归基线。本模块不复制旧 10 轮固定流程，改为按「入口 + 卡点」动态推进，每轮一个主要目标。新模块须通过用户验证后才入口迁移，回归通过前旧实现不退役。
