# 概念关系（自我认知模块）

> 本文件整理概念之间的因果与条件关系。每个关系统一按四问展开：**什么条件下影响什么 / 如何识别 / 怎样推进 / 何时不成立**。全文已脱敏。
>
> **证据等级**：主体 A2（七课同期笔记，非逐字稿）+ B 层（SOP）；关系中的「什么条件下影响什么」多为 A2 第七课闭环与 SOP 闭环路径的归纳，逐项回指 A2 课次。

## 一、伤害 → 谎言 → 核心信念

- **什么条件下影响什么**：当一个人遭遇伤害并因此失去某种力量时，伤害会带来许多谎言与错误认知；这些谎言在深层沉淀为「对自己的根本性负面定论」，即核心信念。伤害是源头，谎言是中间形态，核心信念是沉淀后的底层定论。
- **如何识别**：从「记忆中最伤害的一件事」入手（第 5 课），看这件事拿走了什么力量、留下了什么「对自己的结论」；谎言表现为「把伤害归因于自己不够好 / 不安全 / 不可爱」等。
- **怎样推进**：用灵魂四问定位（最伤害的事 → 伤害了我的 → 拿走了力量 → 核心信念）——定位由用户自己说出（镜像式），定位一旦完成则明确告知「这个核心信念是穿上真理外衣的羞耻，是错误的」（敢于定性）。
- **何时不成立**：不是所有伤害都必然沉淀为核心信念；若当事人已具备足够支持与修复，伤害可能不固化为核心信念。涉及严重创伤时，单靠认知定位不够，需转专业疗愈。

## 二、核心信念 → 人设（保护机制）

- **什么条件下影响什么**：核心信念是「我不可触碰的痛点」，为了保护自己、远离核心信念，人会生出人设（面具）。核心信念越痛，人设越用力。
- **如何识别**：人设表现为某种自我形象或自我要求（如「我必须完美」「我必须强大」「我必须讨人喜欢」，也可以是「我可不是小气的人」「我是有信仰的人」），其反面正是核心信念（「我不够好」「我很无力」「我不可爱」）。
- **怎样推进**：引导用户说出「因为过去的伤害，我为自己设立了怎样的人设来保护自己」（第 4 课），把人设与它想保护的核心信念连起来看。
- **何时不成立**：并非所有自我保护都源于核心信念；人设保护核心信念的关系在任何阶段都成立；正常的边界与防御不等同于人设。

## 三、人设 → 反噬

- **什么条件下影响什么**：人设短期能保护自己，但时间长了，人设与受伤后的自己分不清，人设开始反噬——它延续过去的伤害继续伤害现在的自己，并阻挡自己获得真正想要的东西。
- **如何识别**：人设的「保护」开始变成「束缚」：因为「必须完美」而不敢犯错、因为「必须坚强」而无法求助、因为「必须有用」而无法休息；越想守住人设，越得不到真正想要的。
- **怎样推进**：问「现在这些人设怎样延续过去的伤害而继续伤害你？」（第 4 课），点明「这个人设带给我怎样的谎言」。
- **何时不成立**：「已反噬、已痛苦」不是适用前提，人设保护核心信念的关系在任何阶段都成立；它只是推进顺序的提示——先让当事人自己看到代价，再谈卸下。

## 四、焦虑 → 人设受威胁的信号

- **什么条件下影响什么**：焦虑是人设受到威胁时产生的情绪。当事情发生、人设的保护失效、核心信念可能被暴露时，焦虑就会出现。焦虑不是终点，而是线索——顺着它下探，能触到核心信念。
- **如何识别**：焦虑的对象是「表面的那件事」，但真正的痛点是「这件事意味着人设保不住了、核心信念要被证明为真」。表面是「怕这件事」，底下是「怕核心信念成真」。
- **怎样推进**：用「这件事意味着……意味着……意味着……最后触动核心信念」（第 6 课）层层下探，把表面焦虑连接到核心信念。
- **何时不成立**：焦虑若已达临床程度（广泛性焦虑、惊恐发作等），「下探」不能替代治疗；先转专业评估。

## 五、替代思维 → 攻击谎言

- **什么条件下影响什么**：下探到核心信念后，需要反击支撑它的谎言；替代思维是「用来攻击谎言的反向认知」，用更接近事实的表述替换扭曲的认知。
- **如何识别**：找出「支撑核心信念的那句谎言」（如「不完美就完了」），然后用事实反驳它（「不完美 ≠ 失败」「做不好 ≠ 是坏人」）。
- **怎样推进**：第 6 课「寻找替代思维攻击谎言」；第 7 课模板第 2–4、7 步也都在做「攻击谎言」的动作（「然而这是错误的，因为……」）。
- **何时不成立**：替代思维不是「强行积极自我暗示」；当谎言所依附的伤害尚未被看见、情绪尚未被承接时，先接纳再攻击，否则沦为空洞口号。

## 六、拿回力量 → 重树核心信念

- **什么条件下影响什么**：核心信念源于「最伤害的一件事」拿走了某种力量（信任、勇气、安全感等）；拿回这份力量，是重树核心信念的前提。力量找回来，错误的核心信念才有被替换的空间。
- **如何识别**：问「这件事拿走了我什么力量」——当事人能说出一个具体的能力 / 品质（如「拿走了我的安全感」「拿走了我信任人的能力」），即为被拿走的力量。
- **怎样推进**：第 5 课灵魂四问第 3 问定位力量；破局侧沿「攻击谎言 → 打破人设 → 拿回力量 → 重树核心信念 → 活出本相」推进（B 层衍生，元素回指 A2）。
- **何时不成立**：力量不会「凭空拿回」，需要在可验证的现实经验里重新获得（如重新建立一段可信任的关系）；单靠「告诉自己我有力量」不足以重树核心信念。

## 七、原生家庭信息 → 恐惧 → 当前生活影响

- **什么条件下影响什么**：小时候最常听见的信息（一个画面、一个声音）会带来一个「后果预设」式的恐惧（如「不努力就完了」）；这个恐惧延续到成年，持续影响当前的生活选择与应对方式。
- **如何识别**：当前某个「过度反应」或「停不下来」的模式（过度用力、不敢休息、不敢求助、讨好）背后，往往连着一条童年信息带来的恐惧。
- **怎样推进**：第 2 课四问（最常听见的信息 → 带来怎样的恐惧 → 怎样影响现在 → 其中的谎言是什么）逐层溯源，并点破「这个信息里的谎言」。
- **何时不成立**：当前困扰不一定都源于原生家庭；先判断是否真有「反复出现的旧模式」，不要把每个当下问题都硬归因到原生家庭。
