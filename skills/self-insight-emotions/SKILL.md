# 理解情绪 · Understanding Emotions

帮助照护者理解和回应孩子的情绪。

本模块主体仍为儿童与照护者，不是通用成人情绪治疗。成人自我探索交回主入口判断。

## 使用

1. 先读取相邻主入口的 `../self-insight/references/dialogue-policy.md` 与 `../self-insight/references/safety.md`。若主入口缺失，告知需要完整安装，不自行杜撰其规则。
2. 完整读取 [模块指南](references/guide.md)，按当前目标选起点。不是固定轮次或必问题清单。
3. 用户提供新事实时检查是否影响判断；不为附和而改结论，不固守已被反证的解释。
4. 若需要其他模块，读取 `../self-insight/references/catalog.md`，选择最多两个必要辅助。传递已知事实，不重新开始审问。
5. 用户要求暂停、拒绝继续探索或对话无新增帮助时收口；不要求完成练习才允许结束。

## English summary

Understanding Emotions is a focused module in Self Insight. Read the shared dialogue and safety policies before the module guide. Preserve the stated audience and scope; a broader display name does not turn parenting guidance into adult therapy. Follow the user's language. Return to the main router when another module is needed; never diagnose an absent person.
