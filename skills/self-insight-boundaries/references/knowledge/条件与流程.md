# 条件与流程（界限模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进、以及给孩子立界限的分龄要点。全文已脱敏。

## 一、进入条件（什么情境适合进本模块）

当问题的核心落在「责任归属与关系安全」上，即以下任一情形，进入本模块：

- 分不清「我的事 / 你的事」，总替他人兜底、替他人负责，或因别人插手自己的事而困扰；
- 难以拒绝、不敢说「不」，害怕让人失望，常有无来由的罪恶感、焦虑、莫名疲惫；
- 关系中反复被越界、不被尊重，出现被动攻击、憋着怒气或讨好式付出；
- 需要给配偶、孩子、父母或自己立界限，但不知道怎么做、不知道对不对；
- 已经「提了要求」却无效，卡在「没有后果、别人照样越界」这一环；
- 孩子被家庭之外的第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入——此类场景由本模块主导对外处置（情绪模块可辅助接住孩子的情绪）。

## 二、排除条件 / 转介条件（什么情境不进本模块或需转介）

本模块只处理「界限的认知与能力」，以下情境不归本模块，应转介或另配他处：

| 情境 | 处理方向 |
|---|---|
| 具体行为管教的操作手册（孩子某行为如何纠正） | 转「管教」系列模块 |
| 情绪识别、命名与调节技术 | 转「情绪」系列模块 |
| 精神疾病或心理障碍的诊断、治疗 | 转精神/医疗专业，不做诊断 |
| 原生家庭的深度疗愈（深挖童年创伤） | 本模块仅在「童年记忆」层面点到，深挖疗愈转团体辅导/专业治疗 |
| 急性自伤/自杀危机、家暴等人身安全风险 | 立即报警、送医，先保安全再谈界限；以死相胁式操控（无真实计划与手段）按威胁处理、不因威胁让步，有真实计划/手段/既往尝试的立即报警送医 |
| 受精神状况或药物影响、难以自我控制行为 | 先就医处理生理/精神因素，再回来看界限 |

## 三、咨询候选流程（按卡点分环）

顺序即卡点顺序：**认知 → 动机 → 恐惧 → 方法 → 后果 → 应用场景**。每一环先判断卡点在哪，再对症推进；卡点没清，不跳到下一环。

| 环 | 对应课内容 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介条件 |
|---|---|---|---|---|---|
| 认知 | 界限是什么（定义、意象、误解） | 「你说的界限是什么？最近哪件事让你觉得被越界了？」 | 让来访者写出一个「不关你的事 / 不关我的事」的具体场景 | 能用自己的话复述「界限=什么可以/什么不可以」 | 反复在「要不要立」上争执且无认知基础，回本环重打地基 |
| 动机 | 界限缺乏的后果（12 类后果清单） | 「缺了界限，已经给你造成哪些看得见/看不见的后果？」 | 按「父母/工作/朋友/配偶/孩子」分块写下正在经历的界限缺失问题 | 至少识别出 1–2 个与自身强相关的后果 | 因严重焦虑/抑郁无法完成觉察，先转情绪/专业支持 |
| 恐惧 | 害怕立界限的心理机制与克服 | 「你最怕立了界限之后发生什么？」 | 对一个恐惧做认知过滤三问（是事实吗/为何这么说/希望我什么反应）或一次事实核查 | 能区分「真实的危险」与「记忆带来的旧恐惧」 | 触及原生家庭深伤且反复崩溃，转深度疗愈/团体辅导 |
| 方法 | 三种界限模式与建立方法（六步） | 「你分得清健康界限和硬/软界限吗？你现在偏哪种？」 | 用六步法理清一个界限：喜欢/不喜欢→要什么/不要什么→愿做到什么程度→按关系远近定→逐步推进→温柔而坚定 | 产出至少一条可执行的、符合「温柔而坚定」的界限 | 长期在硬/软两端摇摆且情绪失控，回补「恐惧」环或转专业 |
| 后果 | 界限与后果（惩罚 vs 后果、四前提、三步给后果） | 「你立了界限，但有没有配后果？后果你做得到吗？」 | 给一条界限补上「自己能做到 + 先说明 + 与行为相关联」的后果 | 后果满足四前提（能做到/说了一定做/对方可承受/先说明后给予） | 后果给不出或给成惩罚/威胁，回本环辨析惩罚与后果 |
| 应用场景 | 孩子 / 婚姻 / 父母 / 自己 / 对外（学校、老师、邻里、陌生人）五个应用域 | 「这件事发生在哪段关系？那段关系现在远近如何？」 | 选一个关系域，按该域要点立一条带后果的界限 | 至少在一个关系域完成一次「界限 + 后果」闭环 | 涉及人身安全/危机，转介（见上表） |

**对外域要点**：孩子被第三方越界时，家长的介入姿态就是孩子的边界教材——孩子对侵害「没觉得什么」往往意味着身体/权利边界意识尚未建立，淡化处理会让孩子学会议价自己的边界，也就是学会给自己的边界打折。对外介入的动作：按事实定级（不允许淡化）、及时介入（不拖）、当面或正式向对方确立规则、修复孩子对成人权柄的信任（让孩子看到「大人能管事、我的求助有用」）。对方是老师、长辈或权威时，处理方式可以调整，判断与原则不降级。

通用提醒：关系远近决定界限怎么立，情绪连接好不好直接决定方法差异；同一套话术不能照搬到不同关系。

## 四、给孩子立界限的分龄四段

| 年龄段 | 要点 |
|---|---|
| 0–4 岁 | 强调行为与后果，不讲大道理。后果要**可测量、可感官、可视觉化**（如「失去信任」太抽象，换成「不洗碗就没巧克力」）；给出后果前必须**确认孩子听懂**（孩子可能把「下午睡醒」理解成「生日」）。可用视觉/听觉工具（如闹钟）做提醒。 |
| 5–8 岁 | 重点是**理解界限**：把界限写下来或画出来，让孩子能随时看到；说清「妈妈看重的是什么、我的期待是什么」，并告知哪些行为符合这些期待。 |
| 9–13 岁 | 给孩子力量与**重来的机会**，专注奖励而非惩罚；开始解释立界限的原因，并允许**讨价还价**（一起讨论、协商出双方能接受的方案）。 |
| 14–18 岁 | 从大局出发，不陷入权力博弈；**坚定而持续**，夫妻双方像一张网一样形成合力，用稳定的界限给孩子安全感。 |

补充：孩子不接受界限常见三因——不习惯（少给、解释好处）、关系疏远（用对他的爱的语言先补爱，爱与界限缺一不可）、不尊重父母（父母自己没有界限或知错不认，需先立自己、夫妻间、与父母间的界限）。
