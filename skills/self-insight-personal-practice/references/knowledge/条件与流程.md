# 条件与流程（7习惯模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进。全文已脱敏：不出现讲师姓名、课程品牌名、真实学员昵称与可识别地名机构；本模块作为一门独立课程表述，与任何外部作者/框架无关。

## 一、进入条件（什么情境适合进本模块）

当问题的核心落在「父母自身状态」而非「孩子行为」上，即以下任一情形，进入本模块：

- 意识到自己焦虑、失控、情绪化、过度牺牲或过度控制，想从「改变自己」入手，而不是只盯着怎么改孩子；
- 父母自身处于「有家庭、没婚姻」或婚姻质量下滑的状态，意识到婚姻在拖累养育；
- 卡在「只会讲道理、不会接情绪」「不会问问题、孩子不愿聊」「做错了却开不了口道歉」等父母自身的沟通/修复能力上；
- 想给孩子「赋能」却陷入「我控制你 / 你控制我」的对立，孩子越大越对立；
- 明白「先立自己、再立关系、再影响孩子」的方向，但不知道具体从哪个习惯切入、怎么做。

一句话定位：**凡是想「先把自己修好」的父母，进本模块；凡是想「直接改孩子」的父母，另配他处。**

## 二、排除条件 / 转介条件（什么情境不进本模块或需转介）

本模块只处理「父母自身七个习惯」的认知与能力，以下情境不归本模块：

| 情境 | 处理方向 |
|---|---|
| 具体行为管教的操作方法（孩子某行为如何纠正、如何立后果） | 转「管教」系列模块 |
| 孩子的上瘾、情绪识别命名与调节技术 | 转「情绪 / 上瘾」系列模块 |
| 婚姻本身处于危机（家暴、出轨等实质伤害，或婚姻关系本身的修复与辅导） | 转婚姻辅导；本模块只处理「婚姻质量如何影响养育」，习惯层不处理婚姻本身的修复 |
| 原生家庭的深度疗愈（深挖童年创伤） | 本模块仅在「复刻模式 / 处理过去伤害」层面点到，深挖疗愈转团体辅导/专业治疗 |
| 精神疾病或心理障碍的诊断、治疗 | 转精神/医疗专业，不做诊断 |
| 急性自伤/自杀危机、家暴等人身安全风险 | 立即报警、送医，先保安全再谈习惯 |
| 受精神状况或药物影响、难以自我控制行为 | 先就医处理生理/精神因素，再回来看习惯 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 转「界限」系列模块主导对外处置；本模块按分工配合 |

## 三、咨询候选流程（按卡点分环）

**核心原则：不套七课顺序，按用户当前最痛的习惯切入。** 三个环是「卡点顺序」，不是「课程序列」——先定位最卡的那个习惯，再判断它卡在认知还是执行，最后给该习惯的最小行动。

顺序即卡点顺序：**定位最卡的习惯 → 判断卡在认知还是执行 → 给该习惯的最小行动**。每一环先判断卡点，再对症推进；卡点没清，不跳到下一环。

| 环 | 作用 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介条件 |
|---|---|---|---|---|---|
| 定位最卡的习惯 | 找出当前最痛、最拖累养育的一个习惯 | 「最近哪件事让你最失控/最痛苦？它跟下面哪个更像：只顾孩子忘了自己、婚姻在拖累、不学习不成长、只会讲道理、不会问、不会道歉、总想控制？」 | 让来访者用一句话写下「我最卡的习惯是 X，最痛的那一幕是 Y」 | 能明确指出一个（最多两个）最卡的习惯，并说出对应场景 | 反复在多个习惯间摇摆、说不清痛在哪，回本环用「最近一次冲突」具体化；若核心其实是孩子行为问题，转管教模块 |
| 判断卡在认知还是执行 | 区分「不知道」还是「知道做不到」 | 「这个习惯，你是『不知道为什么该做/该怎么做』，还是『知道怎么做但做不出来』？做不出来时卡在哪一步？」 | 让来访者自答：是认知缺（说不清为什么难/怎么做）还是执行难（会说但做不出、一做就崩） | 能明确说出自己卡在「认知」还是「执行」，并指出执行时崩在哪个动作 | 认知层面反复在「要不要做」上争执，回本环重打地基；执行时情绪反复崩溃，转情绪/专业支持 |
| 给该习惯的最小行动 | 针对最卡习惯给出「最小可执行的一步」 | 「如果只做一件很小、现在就能做的事，让这个习惯先动起来，你会选哪一件？」 | 按下面「七习惯最小行动对照」给出该习惯的最小行动，并要求回到下一次反馈 | 产出一条具体的、可操作的、下次可反馈的最小行动 | 涉及人身安全/危机（见排除表）；若最小行动反复做不到且情绪失控，回补「认知/执行」环或转专业 |

通用提醒：同一套话术不能照搬到不同家庭；先照顾自己的情绪状态，再谈改习惯；「先关注自己」不等于「不关注孩子」，紧急安全永远优先。

## 四、七习惯最小行动对照（环 3 落点）

按用户最痛的习惯，直接取用对应最小行动，不必按课序走：

| 最卡习惯 | 卡点特征 | 最小行动 |
|---|---|---|
| 关注自己 | 只盯孩子、不会照顾自己 | 今天为自己做一件与孩子无关的小事（下载一首喜欢的歌、走一条没走过的路、为自己买一份小食），并每天重复 |
| 婚姻质量 | 有家庭没婚姻、貌合神离 | 今天就给配偶一次「柔软开启」的对话，或补一个「正面回应」；识别自己是否中了「麻木/负面沟通/分床」等征兆 |
| 随时学习 | 只求「怎么办」、不成长 | 从身边一件小事问「为什么」（一个产品现象、孩子的一句话），先不问答案，只保持好奇 |
| 情绪比道理更重要 | 只会讲道理、接不住情绪 | 下次孩子有情绪时，先不开口讲道理，只说一句指认他感受的话（「你很难过/很生气，对吗」）；情绪被接住之后，该讲的道理还是要讲——完全不讲道理与只讲道理两个极端一样糟糕 |
| 问对问题 | 孩子不愿聊、问题无效 | 今晚见面先列一个问题清单，只问一个开放式、具体、关于感受的问题 |
| 愿意承认错误 | 做错了开不了口/只会粗糙道歉 | 挑一件最近做错的事，先用七步骤里的「表达情绪 + 陈述行为」两步写下来，再对孩子说 |
| 双赢 | 我控制你/你控制我 | 遇冲突时先不压制，改用「我人称」说一句自己的感受，再和孩子一起列方案 |
