# 概念关系（上瘾模块）

> 本文件整理概念之间的因果与条件关系。每个关系统一按四问展开：**什么条件下影响什么 / 如何识别 / 怎样推进 / 何时不成立**。全文已脱敏，口述数据不写数字。

## 一、情绪需要未满足 → 上瘾

- **什么条件下影响什么**：当孩子在生活中无法获得情绪所需要的满足（被接纳、有力量、归属、被爱、成就），而上瘾物质自带的心理暗示恰好能满足这些需要时，孩子就会用上瘾来填补。情绪需要得到满足，孩子不太会上瘾；得不到满足，就会逃进上瘾物。
- **如何识别**：问「他为什么痛苦」比问「他为什么上瘾」更能定位；上瘾者普遍无法共情、烦躁不安喜怒无常、伴抑郁焦虑、极度悲伤；看片 / 打游戏 / 吸毒时的自述都指向「被需要、有力量、被支持、被接纳」。
- **怎样推进**：先承认自己（父母）给孩子造成的痛苦；用健康途径满足同一项情绪需要（真实朋友、现实成就、无条件的爱），上瘾行为会慢慢淡化。
- **何时不成立**：当情绪需要源于性侵等创伤时，父母层面的满足不够，须转专业；当上瘾已严重到合并其他心理健康问题（如重度抑郁、自伤风险）时，转专业心理辅导，家庭层方法不能替代。

## 二、家庭环境缺陷 → 痛苦 / 创伤 → 上瘾

- **什么条件下影响什么**：家庭环境缺陷（情绪失联、角色错位、缺乏界限、父母成瘾，以及家暴 / 抱怨 / 过度保护 / 放任 / 疏远 / 要求失衡 / 没有自己的生活）会让孩子产生痛苦；若叠加创伤经历（性侵、家暴、校园暴力、目睹死亡 / 自然灾害）或压力（学习、同学、父母三源），情绪需要更难以满足，上瘾风险显著上升。
- **如何识别**：孩子早年出现可预警前兆——喜欢冒险、冲动 / 延迟满足弱、父母有上瘾行为、童年创伤、社会边缘化 / 隔离、与父母情绪失联、角色错位。
- **怎样推进**：逐一正向引导——把冒险引导到有意义的事、训练延迟满足、父母戒断自身成瘾、求助专业判断创伤、建立归属感、建立界限感让父母做父母孩子做孩子。
- **何时不成立**：这些前兆不是「必然导致上瘾」，而是「更脆弱」；健康家庭也会犯错、也会吵架，判断看家庭氛围而非「从不犯错」；创伤是否成立需专业判断，父母不可自行定论。

## 三、界限缺失 → 上瘾预防失效

- **什么条件下影响什么**：当家庭缺乏界限，父母容易把孩子承担不起的责任推给孩子、侵犯孩子隐私、提出不切实际要求、要求孩子对自己的情绪负责；孩子因无法捍卫自己的界限（生存全赖父母）而陷入无能为力的痛苦，只能逃进上瘾物。
- **如何识别**：越界的四表现——不容隐私（看日记、偷听电话）、转嫁超龄责任（让孩子照顾弟妹、替父母关系负责）、不切实际要求、要孩子为父母的情绪负责（「你把我气出病」「你这样做我就去死」）。
- **怎样推进**：父母先立自己的界限，把孩子放回正确角色；具体「立界限 + 后果」的操作细节转「界限」模块；用「温柔而坚定」而非惩罚来执行。
- **何时不成立**：界限缺失只是上瘾的成因之一，不能把一切上瘾都归为「界限问题」；已有界限能力但仍上瘾的，回到情绪根源与分型破解环节。

## 四、多巴胺耐受（成瘾的生理机制）

- **什么条件下影响什么**：致瘾物反复刺激大脑的奖赏中枢（reward center），使多巴胺大量释放，多次后接收器变麻木、产生耐受，必须用更大量、更强烈的刺激才能获得同等愉悦——这就是「越需要越多」的生理基础。
- **如何识别**：原来十分钟就够，现在要半小时、一小时；原来一张图片就够，现在要看片、看更极端的内容；停不下来、不玩就难受。
- **怎样推进**：理解「耐受」不等于「意志薄弱」，是大脑已被改变的生理现实；破解靠满足情绪需要、用真实生活的奖励替代上瘾物带来的快感，而非靠意志硬扛或道德说教。
- **何时不成立**：耐受机制是「上瘾如何维持」的解释，不是「上瘾如何开始」的解释——开始归因仍在家庭环境与情绪需要；上瘾已严重到合并其他心理健康问题（如重度抑郁、自伤风险）时，转专业心理辅导，家庭层方法不能替代。

## 五、上瘾 ↔ 情绪（恶性循环）

- **什么条件下影响什么**：情绪问题（抑郁、焦虑、悲伤）未得到处理会推动上瘾；上瘾又加剧情绪低落、孤立与自我否定，形成滚雪球式的恶性循环。
- **如何识别**：上瘾者情绪共性——无法共情、烦躁不安 / 喜怒无常、普遍伴抑郁焦虑、极度悲伤；越依赖网络越孤单，越孤单越依赖网络。
- **怎样推进**：切断循环的两个抓手——先处理情绪根源（问为什么痛苦），再用健康途径替代上瘾物；提高情绪自省力、识别身体情绪信号、指认引发点、发现身体极限。
- **何时不成立**：当抑郁、焦虑已达临床程度时，仅靠家庭情绪连接不够，需转专业；「上瘾先于情绪」还是「情绪先于上瘾」因人而异，本模块采「相互滚雪球」而非单一方向。

## 六、四类分型的共同机制与各自特点

| 类型 | 共同机制 | 各自特点 |
|---|---|---|
| 网络 | 都是对痛苦的逃避；都走「多巴胺耐受 → 越需要越多」；都是心理问题而非行为问题 | 最普遍；判断看「能否停止」不看时间；危害是灰质 / 白质萎缩、情绪路径改变、社交障碍、语言退步、睡眠不足 |
| 毒品 | 同上 | 最隐蔽，新型毒品伪装成零食 / 饮料；学校越好压力越大吸毒率越高、好学生也吸毒提神；破解靠立界限 + 建双圈子 + 替代 + 停止额外供应 + 主动讨论 |
| 色情 | 同上 | 与性需求无关，与「被接纳、有力量」有关；路径升级（图片→色情片→嫖娼 / 出轨 或 暴力 / 性侵）；破解靠爱情观 + 本体价值 + 父母成为讨论性的第一人 |
| 电游 | 同上 | 父母最关心；游戏公司按五种情绪需求设计，十几分钟捕获玩家；男孩更易上瘾（适应不良认知、奖励敏感性高、心理健康素养低、羞于求助）；破解靠共同定规则 + 挑战性社会活动 + 处理背后心理问题 |
