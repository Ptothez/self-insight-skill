# 条件与流程（上瘾模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进。全文已脱敏，口述数据不写数字。

## 一、进入条件（什么情境适合进本模块）

当问题的核心落在「孩子是否上瘾 + 上瘾背后的家庭与情绪根源」上，即以下任一情形，进入本模块：

- 担心孩子已上瘾，或分不清是「喜欢」还是「上瘾」；
- 孩子开始撒谎、偷玩、为玩手机 / 游戏与父母对抗；
- 家庭正因手机、网络、游戏产生持续冲突；
- 孩子出现作息、成绩、交友、情绪的突然变化；
- 想在上瘾发生前提前预防；
- 孩子已出现前兆或轻中度上瘾，希望先在家庭层面处理（替代、界限、情绪连接）。

## 二、排除条件 / 转介条件（什么情境不进本模块或需转介）

本模块只处理「上瘾的认知、家庭归因与家庭层面的预防破解」，以下情境不归本模块，应转介或另配他处：

| 情境 | 处理方向 |
|---|---|
| 严重上瘾且已引发其他心理健康问题（如重度抑郁、自伤自杀风险） | 转介专业心理辅导；戒网所 / 戒毒所只处理行为不治根 |
| 性侵等创伤成立 | 父母「几乎不太可能帮助到」，立即转专业机构 / 辅导人员 |
| 父母自身未处理的情绪、婚姻、成瘾问题 | 转配套模块（婚姻共进、自我成长等），不在本模块内解决 |
| 具体「立界限」的操作细节 | 界限战术细节转界限模块；界限缺失的诊断与归因留在本模块 |
| 家长想找「几句话让孩子不玩」的速成方案 | 澄清预期：无捷径，需父母长期行动 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 需要家长对外介入时，本模块先给出即时处置方向；长期界限战术细节再转界限模块 |

## 三、咨询候选流程（按卡点分环）

顺序即卡点顺序，**不套课程顺序**：判断真假上瘾 → 找痛苦根源 → 家庭环境自查 → 分型破解 → 家庭执行。每一环先判断卡点在哪，再对症推进；卡点没清，不跳到下一环。

| 环 | 对应课内容 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介条件 |
|---|---|---|---|---|---|
| 判断真假上瘾 | 第一课（判断信号）+ 实操第一课（替代而非限制） | 「能不能自己停下来？有没有为玩撒谎？不玩会不会发疯？」 | 用信号清单自测，写下一个「失控 / 依赖 / 撒谎」的具体表现 | 能判断是喜欢还是上瘾 | 已确诊严重成瘾或合并自伤自杀风险，转专业 |
| 找痛苦根源 | 第四课（情绪根源） | 「与其问为什么上瘾，先问孩子为什么痛苦？」 | 指出上瘾行为在满足孩子哪一项情绪需要（被接纳 / 力量 / 归属 / 被爱 / 成就） | 能说出上瘾行为背后的情绪需要 | 痛苦源于性侵等创伤，父母无法处理，转专业 |
| 家庭环境自查 | 第二课（家庭环境）+ 第三课（伤害与压力类型） | 「家庭环境的哪些环节可能制造或放大了孩子的痛苦？」 | 自查情绪失联 / 角色错位 / 缺乏界限 / 父母成瘾四项，认领家庭的部分 | 能承认家庭环境对孩子的影响 | 涉及家暴等人身安全风险，先保安全 |
| 分型破解 | 第五、六、七课（网络 / 毒品色情 / 电游） | 「是哪种上瘾？最困扰的是哪一类？」 | 按对应分型落地一条方法（网络建工具思维 / 毒品立界限 + 圈子 / 电游共同定规则） | 找到对应类型的破解抓手 | 毒品 / 色情已升级到违法或暴力行为，转专业 |
| 家庭执行 | 实操第一～七课 + 第三课（预防三层面） | 「替代、界限、情绪连接，哪个还没做？」 | 立一条带后果的界限 + 一个可替代的真实爱好 | 完成一次「替代 + 界限 + 情绪连接」闭环 | 孩子出现砸东西、打人、失控，先报警 / 送医 |

通用提醒：各环都要回到「为什么痛苦」而非停在行为层；父母不参与改变，孩子不可能破解——用同样的方式对待孩子，上瘾只会越来越深。
