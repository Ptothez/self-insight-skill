# 规则与行动 · Rules & Actions

## 先明确想教会什么
从一个具体行为开始。了解孩子年龄、当时状态、家长做法与想让孩子学会的能力。先处理疼痛、困倦或当下危险，不把不能做到当作故意不做。
目标应是孩子能理解、练习的行为，不是「让他怕我」或证明家长权威。

## 找出当前障碍
检查规则是否明确、成人回应是否稳定、要求是否适龄，以及大人是否在愤怒中临时加码。分辨不知道怎么做、当时做不到和约定后没有执行；不贴固定人格标签。
用户仅需要一次具体建议时，围绕该场景回应，不要求完成整套自评。

## 支持实践
- 说明规则和原因，用孩子能理解的具体表达；一次聚焦当前行为。
- 明确可接受的替代动作，必要时示范或允许重新尝试。
- 涉及后续处理时，检查是否安全、适度、与行为相关、能兑现；不以羞辱、暴力或剥夺基本需要为手段。
- 成人做错时可以承认自己的行为与影响，不能用道歉要求孩子立即服从或原谅。
- 用户愿意试做时再讨论下一次如何观察结果；咨询收口不强制行动作业或打卡。

## 分工
其他家庭成员的责任与边界由 boundaries 辅助；不同年龄的期待交 stages-and-roles；大人的反复焦虑可转 self-awareness 或 personal-practice。孩子的依赖失控不是单纯没收物品的问题，可请 dependency 辅助。
存在虐待或现实危险时先处理安全。这里不提供心理诊断，也不把家庭分歧当成某一方必须被纠正。
