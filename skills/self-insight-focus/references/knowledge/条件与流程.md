# 条件与流程（专注力模块）

> 本文件说明：什么情境进入本模块、什么情境转介他处、咨询候选如何按卡点分环推进。全文已脱敏。

## 一、进入条件（什么情境适合进本模块）

当问题的核心落在「对专注力的认知与日常养育」上，即以下任一情形，进入本模块：

- 孩子做作业拖拉、走神、坐不住、丢三落四，家长被「陪作业」折磨；
- 家长怀疑「孩子是不是多动症」，想先做家长初判；
- 家长用奖励、惩罚、吼、讲道理都无效，做了很多技巧却不见效；
- 家长对专注力有错误期待（如认为十分钟作业就该十分钟做完、拿别家孩子比较）；
- 愿意先改自己再改孩子、想学底层逻辑并量身定制方案的家庭。

## 二、排除条件 / 转介条件

本模块只处理「专注力的认知与日常养育」，以下情境不归本模块，应转介或另配他处：

| 情境 | 处理方向 |
|---|---|
| 疑似真 ADHD（已过初判门槛） | 转专业机构/医生做临床诊断与用药，本模块不做诊断、不给药 |
| 网络/游戏/电子产品成瘾 | 转「不上瘾」系列模块（本模块只把「看电视入迷」当作「不算专注力」的反例） |
| 具体学科学习方法（数学/语文等） | 本模块只给通用方法，不系统性教授学科技巧 |
| 完整的管教/纪律体系 | 转「管教」系列模块 |
| 完整的情绪管理（情绪识别/调节） | 转「情绪」系列模块 |
| 精神疾病或心理障碍的诊断、治疗 | 转精神/医疗专业 |
| 急性自伤/自杀危机、家暴等人身安全风险 | 立即报警、送医，先保安全再谈专注力 |
| 孩子被家庭之外第三方（同学、老师、其他成人）越界、侵害或不当对待，需要家长对外介入 | 转「界限」系列模块主导对外处置；本模块按分工配合 |

## 三、咨询候选流程（按卡点分环）

顺序即卡点顺序：**辨期待 → 排病理 → 查环境 → 对发育 → 给方法 → 借关联能力 → 纠心态**。核心原则：先判断是「真专注问题」还是「期待错了 / 环境问题 / 发育未到」，再对症给方法；卡点没清，不跳到下一环。

| 环 | 卡点 | 最少必要询问 | 每轮最小行动 | 停止条件 | 转介/退出条件 |
|---|---|---|---|---|---|
| 辨期待 | 是不是「期待错了」 | 「你说的专注问题具体在什么情境？几分钟的作业用了多久？孩子几岁？」 | 用年龄 ×3–5 分钟（五岁以上）测算合理专注时长，判断期待是否过高 | 能区分「真走神」与「期待过高」，确认期待错就退回纠正 | 确认只是期待错，不必进入病理判断 |
| 排病理 | 是不是「真多动症」 | 「这些表现持续多久了？只在一个场合还是多个场合？12 岁前就有吗？」 | 对照 AD/HD 表征与统一诊断条件做家长初判 | 能基本排除或识别疑似 | 疑似真 ADHD，转专业机构，不做诊断不给药 |
| 查环境 | 是不是「环境/前提问题」 | 「家里氛围怎么样？父母关系怎么样？你怎么理解育儿？」 | 从家庭条件/婚姻/认知三点各列一个缺口 | 识别出至少一个前提缺口并知道怎么补 | 存在家暴/婚姻危机，先处理安全与关系 |
| 对发育 | 是不是「发育未到」 | 「你平时怎么跟他讲时间、讲道理？他几岁？」 | 把一处抽象时间/道理换成视觉或情绪辅助 | 能说出与孩子左右脑发育阶段匹配的方法 | 大孩子不是不必用视觉法，而是换成自己编故事、自设信号、自画时间轴（原理同源、形式随年龄换） |
| 给方法 | 对症给日常方法 | 「睡眠够吗？你观察过他的专注旺盛点吗？你会打扰他吗？」 | 从七大法宝选 1–2 项落地（如九点半前睡熟、设一个短目标） | 至少落地一项 | 睡眠/生理问题持续，先就医排除 |
| 借关联能力 | 用创造力/毅力/好奇反哺 | 「孩子平时提问多吗？你允许他失败、烦躁吗？」 | 从创造力/毅力/好奇各选一个动作落地 | 至少落地一项关联能力动作 | 无（此环为加分杠杆） |
| 纠心态 | 父母完美主义 | 「你对他有没有完美主义的要求（各方面都要好、不出错）？」 | 列出自己的一处完美期待并道歉/调整 | 识别出至少一处完美期待并调整 | 抑郁/焦虑达临床程度，转专业支持 |

通用提醒：专注力是结果变量，父母是入口；每环都先看「父母该改什么」，再看「孩子该练什么」。

## 四、分龄提醒（专注力期待）

- **五岁以下**：不套年龄公式；此时孩子左脑（时间/道理）未发育，用视觉/情绪而非讲时间讲道理。
- **五岁以上**：可用「年龄 ×3–5 分钟」估专注时长；专注递减快，别安排过长时段。
- **看电视不算**：任何年龄都别用「看电视坐得住」衡量专注力。
