# 概念关系（专注力模块）

> 本文件整理概念之间的因果与条件关系。每个关系统一按四问展开：**什么条件下影响什么 / 如何识别 / 怎样推进 / 何时不成立**。全文已脱敏。

## 一、大脑发育 → 专注力

- **什么条件下影响什么**：右脑（情绪/视觉/想象）出生即高速发育，左脑（逻辑/语言/时间）约七岁后快速发育、25 岁前未成熟。在左脑未成熟的阶段，孩子无法处理抽象的时间与道理，于是「讲 20 分钟」「讲道理」都推不动专注力。
- **如何识别**：对低龄孩子讲「还有十分钟/二十分钟」无效，讲完道理转头就玩；孩子听得进颜色、声音、图像，听不进「分钟」和道理。
- **怎样推进**：用右脑补左脑——视觉辅助时间（颜色闹钟绿→黄→红、沙漏、一圈圈走的时间）、视觉辅助语言（情绪脸谱指认、打开柜子指实物）、情绪辅助逻辑（用饱满情绪让孩子理解「痛」）。
- **何时不成立**：七岁不是魔法开关，大脑 25 岁前都在发育定型，八岁九岁十岁也不等于「必须做到」；视觉辅助的原理同源、形式随年龄换，大孩子可换成自己编故事、自设信号、自画时间轴；「左右脑分工/25 岁成熟」是简化科普表述，不作绝对分界。

## 二、睡眠（及运动）→ 专注力

- **什么条件下影响什么**：睡眠中大脑连接点（突触）大量产生；睡眠不足会让专注力、记忆力、脾气、荷尔蒙全面下降。5–7 岁孩子应睡 11 小时以上，建议九点半进入深度睡眠。
- **如何识别**：五六七岁孩子长期只睡约 8 小时；晚上十点十一点还没睡熟；白天易累、易走神、易怒。
- **怎样推进**：九点半前睡熟；观察孩子最易走神的生理时机（饿/累/困），先满足需求——饿了先吃、累了先睡半小时，再做专注任务。
- **何时不成立**：「11 小时/九点半」是课程经验建议，非诊断标准，持续严重睡眠问题应就医排除生理原因；运动在本模块只作为「观察孩子专注旺盛点」的候选之一（艺术/运动/体育）与「高精力更易专注」出现，未单独展开「运动→专注力」的因果，不可据本模块当作定论。

## 三、兴趣 / 激情 → 专注力

- **什么条件下影响什么**：孩子对热爱的事（喜欢的游戏、活动）会自发专注、反感打扰，无需培养；找到「激情所在」（喜欢不够、要热爱）是专注力最强的支点。
- **如何识别**：做喜欢的事时专注且嫌人打扰，做枯燥的事时走神、趴桌、失去兴趣。
- **怎样推进**：帮孩子找激情——让他自己选、观察他做什么最兴奋、用「你觉得呢」引导；别替他选（小提琴与钢琴之外，也许他爱打鼓）。
- **何时不成立**：热爱只对「热爱的事」成立，无法直接迁移到「必须做但不热爱的事」（如作业），那部分要靠短目标、日常惯例、视觉辅助等方法补足；只给兴趣不给其他方法，仍是「半套」。

## 四、环境（干扰 / 屏幕 / 家庭氛围）→ 专注力

- **什么条件下影响什么**：家庭氛围（明亮温暖 vs 争吵冰冷）、父母婚姻、父母育儿认知是专注力的土壤；家长频繁打扰（喂水、端水果、换新玩具、频繁换活动）会打断孩子刚建立的专注；电视/屏幕因闪动性屏蔽孩子大脑的基本动作，不能作为专注力的证据。
- **如何识别**：看孩子在做喜欢的事（乐高/画画/涂色/玩沙）时能否安坐——能坐住可降低嫌疑，但排除仍须按统一条件走完；家长总在孩子专注时进出、切换活动。
- **怎样推进**：不打扰（不以爱的名义打断）、不频繁换新东西（每次换新都要重新建立专注）、让孩子按自己的节奏进入再出来；屏幕时间一律不作为专注力衡量标准。
- **何时不成立**：电视偶尔能坐住不能排除严重多动（也不能作为评判背景）；屏幕/电子产品成瘾的完整干预不属于本模块（转「不上瘾」系列）；家庭氛围中若存在家暴/婚姻危机，先处理安全与关系，再谈专注力。

## 五、父母期待 → 专注表现

- **什么条件下影响什么**：错误的期待（十分钟作业十分钟做完、曾经专注过就该持续、拿别家孩子比）几乎等于把一个他几乎达不到的目标交给他，孩子挫败、罪恶、逃避父母，关系恶化；期待过高（按分钟排课、连续数月无休）反而让成绩下降。
- **如何识别**：父母用大人标准衡量孩子；「他都能做到你为什么不能」；补课越补越多、成绩越补越差。
- **怎样推进**：用年龄 ×3–5 分钟（五岁以上）校准期待；凡事有时、接受不同（专注方式、性格、节奏不同）；预留发呆/东摸西摸的时间（那是大脑属性，不是不专注）。
- **何时不成立**：公式是经验公式（出处待核），五岁以下不宜套用；校准期待不等于放弃要求——那会滑向「放任」这个另一极端。

## 六、毅力 / 好奇 / 创造力 → 专注力

- **什么条件下影响什么**：三者都是「间接反哺专注力」——有毅力的人做一事必专注；好奇心让思维活跃（活跃才易专注）、高精力更易专注、打开新天地；有创造力的人在创作时自然专注。
- **如何识别**：孩子对枯燥学习走神，但对有想象空间、可探索的任务投入；见不得孩子失败/烦躁的家长，反而养不出毅力。
- **怎样推进**：创造力——让孩子带着你玩、提问不急着给答案、假设情景提问、请孩子解决家里问题 + 允许弄脏弄乱；毅力——找激情、鼓励舒适区外挑战、允许生气失败、分享「失败且没成功」的经历；好奇——家长开放思维（「为什么不可以」）+ 引导高质量提问（从「水为什么流动」延伸到「冰水互化」）。
- **何时不成立**：毅力里的「不怕」不是「什么都怕也不怕」（那叫傻子）；允许失败≠放任不管；三者是与日常方法并行的一条路径，和睡眠、不打扰等方法并用更稳。

## 七、焦虑压力 / 安全感 → 专注力

- **什么条件下影响什么**：完美主义让家庭高压、孩子如履薄冰 → 杏仁核长期张开（不安全）→ 专注力、学习能力、接收新知的能力全面下降；长期挫败让孩子越来越不快乐、注意力越来越糟。
- **如何识别**：孩子长期活在「我有没有做错、有没有达标」里；父母「我要求 100 分你才给我 80 分」的求高得低心态；高学历高成就父母仍养出抑郁孩子。
- **怎样推进**：区分卓越与完美；欣然接受并拥抱孩子的缺点与弱点（期待他会犯错、会有改不掉的缺点），让「被接纳」带来安全感，安全感让能力爆发。
- **何时不成立**：抑郁/焦虑已达临床程度需专业治疗，光改父母心态不够；「接纳」不是「放任不管」。
